# Easy Questions Images

This folder should contain images for the 10 easy riddle questions.

## Required Images:

Place the following images in this folder:

- `1.jpg` - Image for riddle 1 (Neil Armstrong)
- `2.jpg` - Image for riddle 2 (Leonardo da Vinci)
- `3.jpg` - Image for riddle 3 (Mahatma Gandhi)
- `4.jpg` - Image for riddle 4 (Christopher Columbus)
- `5.jpg` - Image for riddle 5 (Thomas Edison)
- `6.jpg` - Image for riddle 6 (Bob the Builder)
- `7.jpg` - Image for riddle 7 (Harry Potter)
- `8.jpg` - Image for riddle 8 (Simba)
- `9.jpg` - Image for riddle 9 (Mahatma Gandhi)
- `10.jpg` - Image for riddle 10 (Mickey Mouse)

## Image Guidelines:

- Use `.jpg`, `.jpeg`, or `.png` format
- Recommended size: 800x600 pixels or similar aspect ratio
- Keep file size under 500KB for faster loading
- Images should be relevant to the riddles

## Note:

The riddles are stored in `riddle.json` in this same folder.
