# Hard Questions Images

This folder should contain images for the 5 hard difficulty questions.

## Required Images:

Place the following images in this folder:

- `1.jpg` - Image for hard question 1
- `2.jpg` - Image for hard question 2
- `3.jpg` - Image for hard question 3
- `4.jpg` - Image for hard question 4
- `5.jpg` - Image for hard question 5

## Image Guidelines:

- Use `.jpg`, `.jpeg`, or `.png` format
- Recommended size: 800x600 pixels or similar aspect ratio
- Keep file size under 500KB for faster loading
- Images should be relevant to the questions

## Note:

The questions and answers are stored in `questions.json` in this same folder.
You should update the questions in `questions.json` with your actual hard difficulty questions.
